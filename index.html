Diese App braucht Google Chrome oder Microsoft Edge auf einem Computer.
Spooky2 schliessen, dann «Generator hinzufügen» und den COM-Anschluss wählen. Bereits erlaubte Generatoren verbinden sich beim Start von selbst.

Generatoren zuordnen

Jeder verbundene Generator zeigt jetzt einen Code ab 101 auf dem Display (Ausgänge aus). Geh dem Regal entlang und trag bei jedem Gerät den Code ein, den sein Display zeigt. Zeigt ein Display keinen Code (z. B. 000), Feld leer lassen.
